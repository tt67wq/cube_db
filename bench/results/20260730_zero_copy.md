## 本次变更

### 1. Zero-copy getBorrowed (commit `8010f02`)

新增 `ReadTxn.getBorrowed(key)` API，直接返回页 payload 中的借用切片：

- **内联值（≤3800B）**：真正零拷贝，返回指向页缓冲区的指针，无 `allocator.dupe`
- **溢出值（>3800B）**：返回 null，调用方 fallback 到 `get()`
- **MVCC 安全**：COW 保证旧页不被覆写，借用切片在 ReadTxn 生命周期内有效

预期效果：get 100B 从 35.53us 降至 ~10us（消除 70% 的 `allocator.dupe` 开销）。

### 2. Benchmark bug 修复 (commit `559a214`, @rigor)

- **🔴 WriteTxn.commit 静默吞 error**：`_ = try f.wait()` 丢弃了 OpResult error，导致 put/delete 返回 success 但数据未写入
- **🟡 mapsize 没算 overflow 页**：10KB value 的溢出页分配导致 MapFull
- 修复后 benchmark 12/12 cells 全通过
