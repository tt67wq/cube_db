**Commit**: `57e18cd`  
**Date**: 2026-07-30  
**Machine**: Apple M1 Pro / 8 cores / macOS  
**Zig**: 0.16.0  
**Config**: `zig build bench -Doptimize=ReleaseFast -Dbench-scale=small`  
**Backend**: MemPageStore (in-memory, no fsync)

---

## 优化概述

本次优化解决 [瓶颈 #1：COW 写路径逐页分配](../docs/perf-analysis-20260730.md)，分三阶段实现：

| Phase | 优化内容 | 核心改进 |
|-------|---------|---------|
| Phase 1 | Arena allocator | `applyBatch` 内用 ArenaAllocator 替代直接 allocator，消除 ~145 次 mmap/munmap |
| Phase 2 | Branch in-place COW | Branch 无分裂时直接 copy 页 + patch 4 字节 child 指针，零堆分配 |
| Phase 3 | Leaf in-place COW | Leaf 无分裂时在 stack buffer 直接拼新 payload，零堆分配 |

## 关键发现

1. **Arena 是最大收益来源**：从 505us → 122us（4.1×），消除 ~145 次 mmap/munmap syscall
2. **Leaf COW 进一步提升**：122us → 108us（额外 1.13×），避免 Leaf decode/encode 的 memcpy
3. **Branch COW 收益有限**：122us → 119us，Branch 层不是主要瓶颈
4. **10KB put 提升显著**：2005us → 859us（2.3×），Leaf COW 避免了大 value 的 decode/re-encode
5. **读路径未动**：get/select/compact 持平，验证优化仅影响写路径
